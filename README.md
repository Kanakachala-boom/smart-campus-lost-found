# Smart Campus Lost & Found System

A centralized digital platform for reporting, searching, and managing lost and found belongings across campus.

## Overview
This repository is the shared codebase for our 4-member college project team.

## Getting Started for Collaborators
1. Clone the repository:
   ```bash
   git clone https://github.com/Kanakachala-boom/smart-campus-lost-found.git
   ```
2. Navigate to the project directory:
   ```bash
   cd smart-campus-lost-found
   ```
